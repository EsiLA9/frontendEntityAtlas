# Data Display 展示审计

本审计覆盖 `src/data/display/index.js` 中的全部 13 条实体。判断依据是当前 `src/views/preview-renderer.js` 的 renderer 映射、`src/components/entity-demo.js` 的实际分支，以及专用 `Card` 组件的挂载结果。`Match` 表示实体声明与当前 demo 的对应程度；`Significance` 表示定义中的关键行为是否足够明显。除 `Card` 外，Data Display 当前没有专用 renderer；通用 `EntityDemo` 只代表它实际提供的最小交互，不能视为完整的数据展示组件。

## 统计

按 `Match` 统计：High **1**、Medium **2**、Low **10**；共 **13** 条审计记录。按 `Significance` 统计：High **2**、Medium **1**、Low **10**。翻译字段 `definitionZh` 和 `useZh` 已为 13 条实体全部补齐。`table` 是唯一同时清晰呈现其核心数据形态与可操作行选择的实体；`data-grid` 虽然复用了同一张表，但未实现数据网格的编辑与操作能力，因此单独评为 Low。
