# Selection 展示审计

本审计覆盖 `src/data/selection/index.js` 中的 7 条实体。判断依据是当前 `src/views/preview-renderer.js` 的 renderer 映射与回退逻辑，以及 `src/components/entity-demo.js` 的实际分支、DOM 内容和事件行为。当前 Selection 实体没有专用 renderer：`select`、`combobox`、`multi-select`、`picker` 共用原生选择框分支；`segmented-control` 使用单选项分支；`reference-field` 使用文本输入分支；`scope-selector` 使用通用状态切换分支。`Match` 表示实体声明与当前 demo 的对应程度；`Significance` 表示定义中的关键行为是否能被用户明显感知。

## 逐条审计

| Entity | Claimed concept | Actual demo | Visible result | Interaction | Match | Significance | Gap |
|---|---|---|---|---|---|---|---|
| `select` — Select / 单选选择器 | **Definition:** 从一组已知选项中选择一个值的控件。<br>**Use:** 选择模式、类别、类型、状态或其他受约束的单个值。 | `preview.renderer = select` 没有专用构造器；`renderPreview()` 回退到 `EntityDemo`，由 `kind() = select` 进入 `buildSelect()`。 | 一个原生 `<select>`，显示 `Default / 默认`、`Primary / 主要`、`Secondary / 次要` 三个选项；初始选中第一项。 | 打开原生下拉列表并选择另一项后，页面状态输出会显示 `Selected: ...`；原生控件也提供浏览器默认的键盘选择行为。 | **High** | **High** — 用户能直接看到一个单值选项集合并完成选择，定义中的核心行为清晰可见。 | 选项只是通用示例；没有演示自定义下拉外观、分组、异步加载、创建选项、禁用或无效状态。 |
| `combobox` — Combobox / 可搜索选择框 | **Definition:** 将输入框与建议列表结合，允许用户输入并从匹配选项中选择。<br>**Use:** 在较大的选项集合中搜索角色、引用对象、命令、位置或其他内容。 | `preview.renderer = combobox` 没有专用构造器；`EntityDemo` 的 `buildDemo()` 因 `has('combobox')` 进入 `buildSelect()`，不是输入框加建议列表的专用实现。 | 一个原生 `<select>`，只有 `Default / 默认`、`Primary / 主要`、`Secondary / 次要` 三个选项；没有文本输入、建议列表或加载指示器。 | 用户可以打开并选择单个选项，改变后显示 `Selected: ...`；不能输入关键词、筛选建议、接受自由文本或体验异步查找。 | **Low** | **Low** — 只有“从列表选择”的泛化行为可见，组合框最具辨识度的输入与匹配建议行为不可见。 | 缺少可输入的 textbox、建议过滤、键盘高亮与确认、清除按钮、无结果/加载状态、自由文本和异步查询。 |
| `multi-select` — Multi-select / 多选选择器 | **Definition:** 允许从同一组选项中选择多个值的选择控件。<br>**Use:** 选择标签、能力、筛选条件、类别以及多个相关引用。 | `preview.renderer = multi-select` 没有专用构造器；`EntityDemo` 因 `has('multi-select')` 进入 `buildSelect()`，使用单值原生 `<select>`。 | 一个普通单选下拉框，显示 `Default / 默认`、`Primary / 主要`、`Secondary / 次要`；没有复选框、标签 token、已选数量或 `Clear all`。 | 只能选择一个当前选项，变更时显示 `Selected: ...`；不能同时保留多个选择、移除单项、全选或清空。 | **Low** | **Low** — 当前控件实际展示的是 Select 的单选行为，无法让用户观察多选的核心差异。 | 缺少 `multiple`/listbox 语义、复选项、已选标签、移除单项、全选、清空、筛选和应用操作。 |
| `segmented-control` — Segmented Control / 分段控制器 | **Definition:** 以相邻分段呈现的紧凑型互斥选项组。<br>**Use:** 切换设备预览、编辑/预览/运行模式、对齐方式或视图密度。 | `preview.renderer = segmented-control` 没有专用构造器；`EntityDemo` 因 `has('segmented')` 进入 `buildChoice()`，创建 `role="radiogroup"` 和三个 `input type="radio"`。 | 一个单选组，显示 `Option A / 选项 A`、`Option B / 选项 B`、`Option C / 选项 C`，第一项初始选中；不是相邻分段样式，也没有使用预览示例中的设备标签。 | 选择其他单选项会更新选中状态，并显示 `Selected: Option ...`；没有分段之间的左右方向键处理或内容/视图切换。 | **Medium** | **Medium** — 互斥选择这一关键行为清楚可见，但紧凑分段外观和“切换模式/视图”的语义不明显。 | 缺少相邻 segment 容器、selection indicator、设备/模式等真实标签、左右方向键行为、禁用段和由选择驱动的内容变化。 |
| `picker` — Picker / 对象选择器 | **Definition:** 从集合中选择引用对象的丰富选择器，而不是只选择简单标量值。<br>**Use:** 选择角色、资源、图标、定义、文件或其他领域对象。 | `preview.renderer = picker` 没有专用构造器；`EntityDemo` 因 `has('picker')` 进入 `buildSelect()`，没有对象浏览器或候选预览。 | 一个原生 `<select>`，显示三个通用标量选项；没有搜索框、类型筛选、结果集合、候选预览或选择操作按钮。 | 用户可以在三个选项中选择一个，状态输出显示所选文本；不能搜索、按类型筛选、预览候选对象或清除引用。 | **Low** | **Low** — 预览表达了最基础的“选择一个值”，但没有表达对象选择器的丰富对象关系。 | 缺少对象卡片/结果列表、搜索、类型过滤、候选预览、对象引用、清除动作、无结果和加载状态。 |
| `reference-field` — Reference Field / 引用字段 | **Definition:** 显示并编辑与另一个可识别对象之间关系的字段。<br>**Use:** 在编辑器中设置所有者、父对象、关联定义、目标角色或资源引用。 | `preview.renderer = reference-field` 没有专用构造器；`EntityDemo` 因 `has('reference')` 进入 `buildText()`，渲染普通 `<input>`，而不是引用字段 renderer。 | 一个带 `aria-label="引用字段"`、占位符 `输入内容 / Type here…` 的文本输入框；没有 `角色：优香 / Character: Yuuka` 的已解析引用预览。 | 输入文字会更新状态输出为 `Value: ... / 已输入`；不能打开 picker、跳转目标、清除已解析引用或显示兼容性校验。 | **Low** | **Low** — 只能看到“填写一段文本”，无法感知字段值是指向另一个对象的关系。 | 缺少已解析对象预览、打开选择器、跳转目标、清除引用、兼容性校验、缺失/未解析状态和验证消息。 |
| `scope-selector` — Scope Selector / 作用域选择器 | **Definition:** 用于选择操作所作用的项目、工作区或领域上下文的协调式选择器。<br>**Use:** 选择项目、模组或区域，切换工作区，以及更改编辑器上下文。 | `preview.renderer = scope-selector` 没有专用构造器；`EntityDemo.kind()` 为 `scope-selector`，未命中选择分支，最终进入 `buildGeneric()`。 | 一个通用按钮 `切换状态 / Toggle state`，旁边显示 `6 states · 4 behaviors`；没有项目、模组、区域选项，也没有当前上下文或面包屑。 | 点击按钮只在 `Ready / 就绪` 与 `Active / 已激活` 之间切换，并更新状态输出；不会切换上下文、级联选项或重新加载作用域数据。 | **Low** | **Low** — 通用状态切换没有呈现“当前作用域决定操作上下文”这一核心关系。 | 缺少作用域标签、当前值、选项列表、级联选择、上下文面包屑、数据重载、未保存工作警告和不可用状态。 |

## 统计

按 `Match` 统计：High **1**、Medium **1**、Low **5**；共 **7** 条审计记录。按 `Significance` 统计：High **1**、Medium **1**、Low **5**。翻译字段 `definitionZh` 和 `useZh` 已为 7 条实体全部补齐。
