# Forms 展示审计

本审计覆盖 `src/data/forms/index.js` 中的全部 17 条实体。判断依据是当前 `src/views/preview-renderer.js` 的 renderer 映射、`src/components/entity-demo.js` 的实际分支，以及 `TextField` 和 `Toggle` 专用组件实际生成的 DOM 与事件行为。`Match` 表示实体声明与当前 demo 的对应程度；`Significance` 表示定义中的关键行为是否足够明显。通用 `EntityDemo` 只代表它实际提供的最小交互，不能视为完整的表单控件实现。

## 逐条审计

| Entity | Claimed concept | Actual demo | Visible result | Interaction | Match | Significance | Gap |
|---|---|---|---|---|---|---|---|
| `text-field` — Text Field / 文本输入框 | **Definition:** A single-line field for entering or editing textual input.<br>**Use:** Names, keywords, identifiers, URLs, short descriptions, and search queries. | `preview.renderer = text-field`，命中 `preview-renderer.js` 中的专用 `TextField`；参数提供中文 label、占位符和英文 `use` 作为辅助文本。 | 带标签的单行 `<input type="text">`，可见 `文本输入框`、`输入内容…` 占位符和辅助说明；初始为空。 | 输入文字会更新字段值并发出 `text-field:input`；触发 change 时发出 `text-field:change`。 | **High** | **High** — 单行输入、标签、占位提示和实际输入行为都直接表达了核心概念。 | 未在该预览中演示清除按钮、前后缀、密码/邮箱变体、校验结果或 loading/disabled 状态。 |
| `textarea` — Textarea / 多行文本框 | **Definition:** A field for entering text that may span multiple lines.<br>**Use:** Notes, descriptions, Markdown, code snippets, comments, and long-form content. | `preview.renderer = textarea` 没有专用构造器；`EntityDemo.kind()` 命中 `has('textarea')`，进入 `EntityDemo.buildText()`。 | 一个 `rows=2` 的原生 `<textarea>`，带 `输入内容 / Type here…` 占位符；没有独立的字符计数器或校验区。 | 输入文本（包括换行）会更新 demo 状态为 `Value: ... / 已输入`。 | **High** | **High** — 用户能直接看到并操作可容纳多行内容的文本区域，定义中的核心差异清晰可见。 | 未演示 resize、auto-grow、字符计数、校验消息、只读或 Markdown/代码编辑能力。 |
| `number-field` — Number Field / 数字输入框 | **Definition:** A numeric field that understands number constraints and numeric editing behavior.<br>**Use:** Dimensions, counts, percentages, currency, levels, durations, and editor properties. | `preview.renderer = number-field` 没有专用构造器；`EntityDemo.kind()` 命中 `has('number')`，进入 `EntityDemo.buildNumber()`。 | 一个初始值为 `40`、范围 `0–100` 的原生数字输入框，两侧有 `−` 和 `+` 按钮。 | 点击 `−`/`+` 会调用原生 `stepDown()`/`stepUp()` 并显示当前值；数字输入框本身也支持直接输入和浏览器原生方向键调节。 | **High** | **High** — 数字类型、范围约束和增减操作同时可见，足以让用户理解它与普通文本框的区别。 | 未演示单位、货币/百分比格式、精度处理、scrub 操作或自定义 invalid/clamped 反馈；直接键入时没有 demo 自定义状态播报。 |
| `checkbox` — Checkbox / 复选框 | **Definition:** A control for independently selecting zero or more boolean options.<br>**Use:** Include hidden layers, accept terms, enable features, or choose multiple filters. | `preview.renderer = checkbox` 没有专用构造器；`EntityDemo.kind()` 命中 `has('checkbox')`，进入 `EntityDemo.buildCheckbox()`。 | 一个原生 checkbox 和 `选择这一项 / Select this option` 标签；初始未选中。 | 点击或用原生键盘操作切换选中状态，状态输出显示 `Checked / 已选中` 或 `Unchecked / 未选中`。 | **High** | **High** — 独立布尔值的选中/未选中变化明确可见，核心行为没有被装饰性内容掩盖。 | 只有一个选项，未演示多选集合、indeterminate、必选校验、禁用或错误状态。 |
| `radio-group` — Radio Group / 单选组 | **Definition:** A group of mutually exclusive controls where one option is selected at a time.<br>**Use:** Choose a rendering mode, layout direction, type, or another small fixed set of alternatives. | `preview.renderer = radio-group` 没有专用构造器；`EntityDemo.kind()` 命中 `has('radio')`，进入 `EntityDemo.buildChoice()`，创建 `role="radiogroup"` 和三个原生 radio。 | 三个互斥选项 `Option A / 选项 A`、`Option B / 选项 B`、`Option C / 选项 C`，第一项初始选中。 | 选择另一项会更新互斥选中状态，并显示 `Selected: ...`；原生 radio 也提供浏览器键盘选择行为。 | **High** | **High** — “同组只能选一个”这一最具辨识度的行为可直接观察和操作。 | 选项仍是通用占位文本，未演示组级必选校验、描述/错误信息、禁用项或选择后更新依赖内容。 |
| `switch` — Switch / 开关 | **Definition:** A control for immediately enabling or disabling a setting.<br>**Use:** Animations, notifications, dark mode, visibility, and other persistent preferences. | `preview.renderer = switch` 命中专用 `Toggle` renderer；其实现使用原生 `<button>`，附带 track、thumb 和 `aria-checked`。 | 一个带轨道和滑块的开关，初始显示 `Off / 关闭`；打开后显示 `On / 开启` 并更新视觉状态。 | 点击或使用按钮键盘操作会在开/关之间切换，更新 `aria-checked` 并发出 `toggle:change`。 | **High** | **High** — 开关形态、即时切换和 on/off 结果都清晰可见，直接对应设置开闭。 | 未演示偏好持久化、pending/loading、disabled、描述文本或切换后真实内容/设置发生变化。 |
| `slider` — Slider / 滑块 | **Definition:** A continuous or stepped control for selecting a value within a numeric range.<br>**Use:** Opacity, volume, zoom, size, intensity, ranges, and other bounded numeric settings. | `preview.renderer = slider` 没有专用构造器；虽然 `EntityDemo.kind()` 命中 `has('slider')`，实际由于分支顺序先命中 `has('number', 'range', 'vector', 'bounds', 'slider')`，进入 `EntityDemo.buildNumber()`。 | 可见的是范围 `0–100` 的数字输入框和 `−`/`+` 按钮；没有 track、range、thumb 或可拖拽滑块。 | 点击 `−`/`+` 会调整数字值并显示状态；用户不能拖动滑块或观察连续/步进滑动。 | **Low** | **Low** — 当前预览实际是 Number Field，滑块最关键的空间轨道和拖拽行为完全不可见。 | 缺少 `input type="range"`、轨道、thumb、拖动、刻度/值标签、范围选择和滑块方向键语义。 |
| `color-picker` — Color Picker / 颜色选择器 | **Definition:** A composite control for selecting, inspecting, and editing a color value.<br>**Use:** Theme colors, layer fills, borders, text color, gradients, and visual presets. | `preview.renderer = color-picker` 没有专用构造器；`EntityDemo.kind()` 命中 `has('color')`，进入 `EntityDemo.buildColor()`。 | 一个原生 `<input type="color">` 颜色控件，初始颜色为 `#ff745e`；没有独立的色相、饱和度或透明度区域。 | 点击颜色控件可打开浏览器原生取色器并选择颜色；颜色变化会显示 `Color: #...`。 | **Medium** | **Medium** — 选择颜色这一核心结果可见且可执行，但“复合控件”的组成和编辑维度不明显。 | 缺少 saturation area、hue/alpha slider、色彩格式切换、通道输入、swatches、吸管和最近颜色。 |
| `date-picker` — Date and Time Picker / 日期时间选择器 | **Definition:** A family of fields and calendars for entering or choosing dates, times, ranges, or durations.<br>**Use:** Schedules, filters, publishing dates, logs, appointments, and time spans. | `preview.renderer = date-picker` 没有专用构造器；`EntityDemo.kind()` 命中 `has('date')`，进入 `EntityDemo.buildDate()`。由于 kind 不包含 `time`，实际生成 `input type="date"`，而不是 datetime-local。 | 一个原生日期输入框；可由浏览器提供日历选择器，但没有单独的时间列表、范围日历或月份导航面板。 | 选择日期后触发 change，状态显示 `Selected: ...`；清空后显示 `No date / 未选择日期`。 | **Medium** | **Medium** — 日期选择本身清楚可见，但实体名称和定义中的 time、range、duration 只实现了其中一部分。 | 缺少时间输入、日期范围、持续时长、禁用日期、前后月份导航、格式校验和独立日历结构。 |
| `search-field` — Search Field / 搜索框 | **Definition:** A search-oriented composite that combines a query field with search actions and optional suggestions or results.<br>**Use:** Global navigation, local collections, command discovery, asset browsers, and filtered lists. | `preview.renderer = search-field` 命中专用 `TextField` renderer，而不是搜索专用组件；参数只提供普通 label、placeholder 和 helper text。 | 一个标准单行文本输入框，带搜索框标签和 `输入内容…` 占位符；没有搜索图标、提交按钮、建议列表或结果区。 | 输入文字会触发 `text-field:input` 和 change 事件并更新字段值；不会提交查询、过滤结果或打开建议。 | **Low** | **Low** — 只能观察“输入查询文字”这一基础部分，搜索字段最有辨识度的搜索动作和结果关系没有体现。 | 缺少 query submit/instant search、清除按钮、autocomplete、recent queries、filters、loading、no results 和结果反馈。 |
| `file-uploader` — File Uploader / 文件上传器 | **Definition:** A composite input for selecting files and communicating their upload lifecycle.<br>**Use:** Images, documents, attachments, imports, assets, and batch uploads. | `preview.renderer = file-uploader` 没有专用构造器；`EntityDemo.kind()` 命中 `has('file')`，进入 `EntityDemo.buildFile()`。 | 一个显示 `选择文件 / Choose file` 的 label，内部包裹原生 `input type="file"`；没有队列、进度条或上传状态面板。 | 点击可打开系统文件选择器；选中文件后状态显示 `Selected: 文件名`。当前没有拖放处理、上传请求、重试或取消动作。 | **Medium** | **Medium** — 文件选择入口是可见且可执行的，但上传器定义中的生命周期只展示了选择这一步。 | 缺少 drag-over/drop、upload/process、queue、progress、success/failed、retry/cancel、remove、preview 和类型/大小校验。 |
| `tag` — Tag / 标签 | **Definition:** A compact visual label that primarily communicates classification or metadata.<br>**Use:** Student, category, status, filter, topic, or other short content descriptors. | `preview.renderer = tag` 没有专用构造器；`EntityDemo.kind()` 命中 `has('tag')`，进入 `EntityDemo.buildDataDisplay()` 的列表分支。 | 三个普通按钮式列表项 `Primary item / 主项目`、`Secondary item / 次项目`、`More items / 更多项目`；没有紧凑 tag 外观、颜色指示器或 `Student` 示例标签。 | 点击某个列表项会切换 `is-selected` class，并显示 `Selected: ...`。 | **Low** | **Low** — 当前是可选列表项，不是用于表达分类/元数据的视觉标签，概念辨识度很低。 | 缺少 tag 容器与标签样式、状态/分类内容、filter 选择语义、removable 行为、颜色指示器和语义状态播报。 |
| `chip` — Chip / 芯片 | **Definition:** A compact information unit that may carry a small amount of interaction.<br>**Use:** Selected filters, people, categories, compact actions, and dismissible values. | `preview.renderer = chip` 没有专用构造器；`EntityDemo.kind()` 命中 `has('chip')`，进入与 tag 相同的 `EntityDemo.buildDataDisplay()` 列表分支。 | 三个普通按钮式列表项，没有 chip 容器、leading icon、avatar、紧凑标签或移除按钮。 | 点击列表项会切换选中样式并显示 `Selected: ...`；没有移除、过滤切换或相关动作。 | **Low** | **Low** — 只有“可选择”这一泛化交互，用户不能从外观或结构上识别 compact information unit。 | 缺少 chip 形态、selected/filter 状态、dismiss/remove、leading icon/avatar、相关操作和轻量元数据显示。 |
| `token` — Token / 输入令牌 | **Definition:** A structured value embedded inside an input system, usually representing a committed choice.<br>**Use:** Search queries, tags, references, recipients, and multi-value fields. | `preview.renderer = token` 没有专用构造器；`EntityDemo.kind()` 未命中任何 token 专门或 data-display 分支，最终进入 `EntityDemo.buildGeneric()`。 | 一个通用 `切换状态 / Toggle state` 按钮和 `6 states · 5 behaviors` 说明；没有嵌入输入框的 `type:student` token、光标或自由文本区域。 | 点击按钮只在 `Ready / 就绪` 与 `Active / 已激活` 之间切换并更新状态；不能提交、编辑或移除 token。 | **Low** | **Low** — 通用状态切换没有呈现结构化值嵌入输入系统这一核心关系。 | 缺少 token container、结构化 label/value、提交、编辑、删除、invalid 状态以及与自由文本输入的组合。 |
| `form` — Form / 表单 | **Definition:** A coordinated group of fields and actions for collecting or editing a related set of values.<br>**Use:** Settings, entity editing, creation flows, authentication, and structured data entry. | `preview.renderer = form` 没有专用构造器；`EntityDemo.kind()` 未命中表单专用分支，最终进入 `EntityDemo.buildGeneric()`。 | 一个通用 `切换状态 / Toggle state` 按钮和状态/行为数量说明；没有 `<form>`、输入字段、提交按钮或取消按钮。 | 点击按钮只切换 `Ready / 就绪` 与 `Active / 已激活`；不会收集、校验、提交或重置字段值。 | **Low** | **Low** — 预览没有显示表单由字段与操作组成的结构，无法让用户理解数据收集流程。 | 缺少真实 form 容器、字段集合、分组、Submit/Cancel、校验错误、reset、Submitting/Submitted 和 dirty 状态。 |
| `field` — Field / 字段 | **Definition:** The semantic wrapper that connects one input control with its label, help, and validation messages.<br>**Use:** Form construction, property editors, settings, and accessible input grouping. | `preview.renderer = field` 没有专用构造器；`EntityDemo.kind()` 未命中 text/reference 等分支，最终进入 `EntityDemo.buildGeneric()`。 | 一个通用 `切换状态 / Toggle state` 按钮和状态/行为数量说明；没有 label、control、helper 或 error 的关联结构。 | 点击按钮只切换 demo 状态；没有可填写的控件、辅助说明或校验消息变化。 | **Low** | **Low** — 通用按钮不能表达 Field 作为语义包装器连接控件与说明的作用。 | 缺少 label-control 关联、helper/error 文本、required 标记、invalid 状态和无障碍描述关系。 |
| `fieldset` — Fieldset / 字段集 | **Definition:** A semantic group of related form fields with a shared legend or description.<br>**Use:** Address fields, appearance settings, radio groups, and advanced editor sections. | `preview.renderer = fieldset` 没有专用构造器；`EntityDemo.kind()` 未命中 fieldset 或 layout 分支，最终进入 `EntityDemo.buildGeneric()`。 | 一个通用 `切换状态 / Toggle state` 按钮和状态/行为数量说明；没有 `<fieldset>`、`<legend>` 或相关字段。 | 点击按钮只切换 `Ready / 就绪` 与 `Active / 已激活`；不能折叠、禁用或校验一组字段。 | **Low** | **Low** — 当前没有共享 legend/description 或字段组结构，字段集概念不可辨识。 | 缺少真实 fieldset/legend、字段集合、组级禁用、可折叠行为、组级错误摘要和无障碍分组语义。 |

## 统计

按 `Match` 统计：High **6**、Medium **3**、Low **8**；共 **17** 条审计记录。按 `Significance` 统计：High **6**、Medium **3**、Low **8**。翻译字段 `definitionZh` 和 `useZh` 已为 17 条实体全部补齐。
