# Advanced 展示审计

本审计覆盖 `src/data/advanced/index.js` 中的全部 34 条实体。判断依据是当前 `src/views/preview-renderer.js` 的构造器映射与 `src/components/entity-demo.js` 的分支顺序、DOM 内容和事件处理。Advanced 的 34 个 `preview.renderer` 均没有命中专用构造器，因此全部由 `EntityDemo` 渲染；这里记录的是实际可操作的最小原型，不把它们描述成已经实现的完整高级组件。

`Match` 表示声明的概念与当前 demo 的对应程度；`Significance` 表示定义中的关键行为是否足够明显。`Low` 特别用于通用状态切换、误路由到其他概念，或只显示了概念的一小部分但无法辨认核心结构的情况。
