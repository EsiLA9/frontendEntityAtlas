# Commands 展示审计

本审计覆盖 `src/data/commands/index.js` 中的 8 条实体。判断依据是当前 `src/views/preview-renderer.js` 的 renderer 映射、`src/components/entity-demo.js` 的分支逻辑，以及实际挂载后的 DOM 和事件行为。`Match` 表示实体声明与当前 demo 的对应程度；`Significance` 表示定义中的关键行为是否能被用户明显感知。Commands 当前没有专用 renderer，因此凡是复用通用导航、动作按钮、状态切换或普通显隐面板的实体，均按实际效果如实评为 Low。源码中没有独立的 `Dirty State` 实体；它只作为 `undo-redo` 的一个声明状态出现，因此在对应审计中记录其未被展示。
